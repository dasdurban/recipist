Save to Recipe App

Add a button to your browser that sends any recipe page straight to The Recipe App.

Once set up, you can be reading a recipe on any cooking site and send it to The Recipe App in a single click — no copying, no pasting, no switching windows to type a URL.

Drag this button to your bookmarks bar:

Save to Recipes

Drag it up to the bar under your address bar. Don't click it yet — dragging is what installs it.

Setting it up

  1. Show your bookmarks bar if it isn't visible. In Safari, Chrome and Edge press ⌘⇧B on a Mac or Ctrl⇧B on Windows. In Firefox press ⌘⇧B / Ctrl⇧B too.
  2. Drag the red button above onto that bar. A new bookmark appears. You can rename it afterwards (right-click → Rename) but don't edit its address.
  3. On Linux, open The Recipe App once first. Linux registers the link the first time the app runs, not when it is installed, so until the app has been opened at least once the browser has nothing to hand the recipe to. Skip this on a Mac or on Windows, where the link is registered when the app is installed.
  4. Test it. Open any recipe page, then click the bookmark. Your browser will ask whether to open The Recipe App — choose Always allow so it never asks again.

That's it. From then on, one click on the bookmark sends the recipe you're looking at into the app, which imports it and shows it to you.

The first click always asks. Your browser has to confirm before letting a website open another app; this is a security feature, not a fault, and "Always allow" settles it permanently.

If you use Safari

Safari asks for confirmation every time and cannot be told to remember. If that becomes tiresome, Chrome, Edge and Firefox all have an "Always allow" option on the first prompt.

What the button actually does

It reads the address of the page you are on and asks the operating system to open recipist://import?url=…. That link only opens The Recipe App, and the app only accepts http and https addresses, so the button cannot be used to run anything or reach anything on your computer. Nothing about the page is sent anywhere; the app fetches the recipe itself, the same way it does when you paste a link into the Import box.

If the app doesn't open

Check that The Recipe App is installed (in /Applications on a Mac, or via the installer on Windows and Linux). Opening a link can only launch an app the operating system already knows about.

On Linux, open The Recipe App once before using the button for the first time. Linux records which app handles recipist:// when the app first runs rather than at install time, so a freshly installed app hasn't claimed the link yet. Once you have opened it, the button works from then on, including when the app is closed; if you move the app afterwards, open it once more so the link is pointed at the new location.

If the button does nothing at all, the bookmark's address was probably edited when it was renamed. Delete it and drag a fresh one from this page.
